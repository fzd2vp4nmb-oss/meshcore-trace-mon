trace-mon — Overview

Italiano ← Back to Dashboard

trace-mon is a diagnostic system for analyzing the RF links of a MeshCore network. It observes a set of predefined paths on a fixed schedule, so that link quality can be tracked over time and later correlated with weather events that occurred during a given period.

1. Trace

Trace monitors a set of trace-paths scheduled by the system, checking the round-trip RF link quality and showing the SNR value for each hop. Data is shown both as a chart and as a table, with the detail of every measurement taken over time.

The current month's data is shown live, with a check every 30 minutes. Past months are archived and available through the Data Source selector, which switches between Live monitoring and monthly archives. The Path selector lets you pick which of the monitored traces to view.

2. Nodes

Nodes shows information extracted from the MeshCore device that acts as this system's tracker. The data is split across a few tables:

  • Device Status shows the device's own status, including the amount of RF traffic transmitted and received over time, both direct and flood.
  • Known Nodes lists every MeshCore node this system has received an advert from over the mesh. For each node you can see its type (chat = Companion, Repeater, or Room Server), when its advert was last received, and the path that advert took to reach this system. This is valuable information: it shows over time how a node's advert reaches the tracking station, with the path changing as the RF links along the way perform differently.
  • Selecting a node shows its full observation history. A set of filters lets you narrow the list down to a given node type, a path of a given length, a path containing a specific node, or a name / public key match.

3. Repeaters

Repeaters queries the local repeater and shows the results across a few tables:

  • Status shows the repeater's own status: transmission data, detected noise floor, and packets sent/received by traffic type (direct or flood).
  • Telemetry shows a set of values read from the repeater's telemetry.
  • Config shows the value of a number of parameters configured on the repeater.
  • Region shows the regional scopes the repeater supports, and therefore which packets it will relay depending on the scope used by the sender.
  • Neighbours lists the repeaters that this repeater has received directly — which other repeaters nearby it hears, with what SNR, and when their advert was last received. This is archived monthly, so past data stays available through the web platform even across a repeater restart.
